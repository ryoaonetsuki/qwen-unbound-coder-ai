📊 Quota planner (Kaggle-first plan)

Kaggle's commonly reported quota is ~30 GPU hours/week. That is ~4.3 hours/day on average — not 6–7. This planner just does the maths; it cannot create hours.

Restart / reconnect (Android)
  1. Open the Colab/Kaggle notebook from this repo on your phone.
  2. Runtime → Run all. Wait for the tunnel URL and for /health to say online.
  3. Paste that tunnel URL above, press Reconnect, then chat.
  4. If the session expired, the model file must be re-downloaded unless the provider kept it (Colab local files do not survive a new runtime; Kaggle datasets/outputs may persist — see docs).
